# DocuMind AI

DocuMind AI helps students and readers find information quickly
in text-based PDFs by asking questions in everyday language.

## Planned MVP

- Upload a text-based PDF and ask questions about its contents.
- Receive answers supported by a filename, page number, and excerpt.
- Receive a clear message when the available evidence is insufficient.

## Project status

Planning completed. Implementation is in progress toward a working
local MVP by December 31, 2026.
